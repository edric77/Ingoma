# Ingoma — Regles produit

## 1. Points

| Action | Points |
| --- | --- |
| Lecon terminee | +10 |
| Quiz reussi (>= 70 %) | +15 |
| Quiz parfait (100 %) | +25 |
| Cas pratique valide | +30 |
| Connexion du jour | +5 |
| Serie de 7 jours | +50 (bonus) |

Les points sont uniquement gagnes par l'apprentissage (pas d'achat).

## 2. Classements

- **National** — tous les inscrits
- **Par ministere / institution** — si renseigne au profil
- **Hebdomadaire** — remise a zero chaque lundi (favorise la regularite)

Affichage type : rang + points, sans confrontation agressive.

## 3. Regularite

- **Streak** : jours consecutifs avec au moins 1 lecon ou 1 quiz
- Badges :
  - 3 jours — *Premier pas*
  - 7 jours — *Semaine solide*
  - 30 jours — *Agent assidu*
- Calendrier d'activite sur le profil
- Mention possible sur le certificat de parcours

## 4. Inscription telephone burundais

- Indicatif **+257**
- Mobile local : **6X XXX XXX** ou **7X XXX XXX**
- Flux : saisie numero → OTP SMS (6 chiffres, 5 min) → profil (nom, institution optionnelle)
- Email optionnel (certificats / notifications)

## 5. Identite visuelle

- **Nom** : Ingoma
- **Symbole** : tambour sacre stylise (peau blanche, etoiles rouges, fut rouge strie, flancs verts, pied rouge)
- **Couleurs drapeau** : rouge `#CE1126`, vert `#1EB53A`, blanc `#FFFFFF`
- **UI** : fond papier creme, vert foret pour le texte / boutons
- Declinaisons : symbole seul (favicon, header) · symbole + mot Ingoma
